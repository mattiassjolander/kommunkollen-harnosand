# Kommunkollen Härnösand

Insyn i hur kommunpolitiken i Härnösand bedrivs.

Projektet samlar in protokoll, handlingar och annan offentlig data från Härnösands kommun, analyserar den och presenterar resultatet på en webbplats där man kan navigera mellan ärenden, nämnder, beslut och ledamöter.
